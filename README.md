# 🔐 Sistema de Autenticación con Spring Security 6

Proyecto de la **Unidad 9 - Seguridad en Aplicaciones Web**.

---

## 🚀 Tecnologías

- Java 21  
- Spring Boot 3  
- Spring Security 6  
- MySQL  
- Spring Data JPA  
- Thymeleaf  

---

## 🔐 Funcionalidades

- Registro con contraseña encriptada (BCrypt)
- Login personalizado
- Autenticación con MySQL
- Roles (ADMIN / USER)
- Protección de rutas
- Logout
